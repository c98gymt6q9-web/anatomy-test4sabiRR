# Анатомия · Коллоквиум 1 — тренажёр

Тест по остеологии и артрологии: 211 вопросов с несколькими верными ответами.

- Ответ засчитывается, только если выбраны все верные варианты и ни одного лишнего
- Блоки по темам или свой диапазон, перемешивание вопросов и вариантов
- Работа над ошибками и статистика (хранится в браузере)
- Режим «Все ответы» с поиском
- Клавиши: 1–5 — выбрать, Enter — проверить / дальше

Открыть: `index.html` в браузере или через GitHub Pages.
